Libre Listener Wallet — settings

Backup & recovery

Your seed lives inside an encrypted backup. Keep a copy — a cleared browser loses the wallet otherwise. Requires the node to be running (start it from the popup).

Recovery phrase & seed

Two forms of the same key — anyone who reads either can spend your funds, so write them down and keep them offline. Both restore this wallet only (extension or web app). Entering the 24 words in another wallet app (BlueWallet, Phoenix, LND…) will not recover your funds — it shows an empty wallet, because those apps derive keys differently. To move funds into another app, set a sweep address you control under Force-close recovery below: if a channel ever closes, the funds land on-chain there.

Google Drive backup

Optional: encrypted backups auto-sync to your Drive's private app folder. Create a Google OAuth Web application client, add the redirect URI below to its authorized redirect URIs, and paste the client ID here. Nothing but the already-encrypted backup ever leaves the extension.

Your channels

Payment channels this wallet holds. Start the node (popup) to load them.

This wallet's node

This is what another node opens a channel to. A browser node can't be dialed, so connect out to the peer first (next section) — then, from that node, open a channel to this Node ID and it arrives over the connection you just made.

Connect to another node

Enter a node's connection info and dial it. The live connection is what lets that node open a channel back to your Node ID (above).

Get a channel from an LSP

An LSP (Lightning Service Provider) opens a payment channel to your wallet for a one-time fee so you can receive payments. Get a quote to see the price — you only pay if you want it. Your wallet needs to be running.

A leased channel can't be force-closed by the LSP before it expires. Clamped to what the LSP offers.

Force-close recovery

If a channel ever force-closes, the wallet sweeps the reclaimed on-chain funds to this address. Set a segwit address (bc1q… / bc1p…) you control — without one, the funds wait unclaimed until you set it, so set it now and recovery is automatic. Can be changed anytime.

Approved sites

Sites you've granted WebLN access, with their daily spending caps.

Danger zone

Delete the wallet on the current network — erases its seed, channel state, and monitors from this browser. Any funds in a live channel will be lost unless you have a backup. Other networks are unaffected.

Developer settings

The defaults are already set up — you only need this if you run your own infrastructure or test on another network.

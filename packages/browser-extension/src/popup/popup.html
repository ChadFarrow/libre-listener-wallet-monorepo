Nostr Wallet Connect (NWC)

Create a pairing string to connect a nostr app (Alby, Damus, …) to this wallet.

⚠️ This wallet only responds while it's running — the browser must be open. Requests sent while it's offline aren't answered, and an invoice you hand out can fail for the payer if the wallet is asleep when they try to pay it.

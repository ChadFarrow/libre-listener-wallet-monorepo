iOS background audio (keep-alive)

Plays a silent audio track so the OS keeps this wallet's node awake while the app is in the background — so boosts from other apps (NWC) can settle in real time instead of only when you reopen the wallet. Uses more battery, and it's best-effort: iOS and Android can still suspend it. On iOS, install to the Home Screen first; on Android, exempt this app from battery optimization.
